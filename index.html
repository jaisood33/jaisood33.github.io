About

Data-driven. Dublin-based.

★ Featured Project

InsightQL

An AI-powered business intelligence interface — type a plain English question, get a SQL query, get a live chart. Built with two sequential Claude API calls: the first generates the SQL, the second executes it against an in-memory database and returns structured JSON. Auto-detects chart type from result schema.

Sample database: 3 Irish-company tables (sales, customers, employees). Includes SQL syntax highlighting, query history, schema browser, and 8 sample question chips.
